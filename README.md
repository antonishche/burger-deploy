# Алгоритмы и структуры данных (АиСД) — БГУ

Репозиторий с моими решениями практических и лабораторных задач по курсу **«Алгоритмы и структуры данных»** (Белорусский государственный университет).

## Структура репозитория

Задачи разделены по тематическим модулям:

* **`General/`** — базовые алгоритмические задачи и разминка.
* **`RecRel/`** — рекуррентные соотношения и динамическое программирование.
* **`SearchTree/`** — деревья поиска (бинарные деревья, обходы, балансировка и операции над ними).
* **`SpecSD/`** — специальные структуры данных (кучи, системы непересекающихся множеств, деревья отрезков и др.).

## Цель проекта

* Закрепление теоретических знаний по курсу АиСД на практике.
* Отработка навыков написания чистого и эффективного кода.
* Формирование собственной базы алгоритмических шаблонов.
